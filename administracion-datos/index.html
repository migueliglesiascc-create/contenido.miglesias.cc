Administración

Panel separado para revisar registros, mantener la base de datos limpia y ejecutar acciones definitivas con confirmación.

! ¡¡¡Atención!!! !
Si continúas con una acción de borrado definitivo, el registro ya no podrá recuperarse. Para el uso normal seguiremos recomendando activar/desactivar desde la Base de datos de Clases de Bolsillo.
